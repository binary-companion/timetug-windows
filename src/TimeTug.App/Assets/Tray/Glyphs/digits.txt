# TimeTug tray digits 1 to 9: original strokes drawn for this project (see README.md).
#
# A digit is a few polylines on a grid of 5 columns and 7 rows. Coordinates are "column,row": 0,0 is the top left
# stroke centre and 4,6 the bottom right one. The renderer scales the grid to the box of the icon size, draws each
# polyline with the stroke width, and draws an outline of the given width around it.
#
# size <icon px> box <glyph width> <glyph height> stroke <px> outline <px>
#   box     the whole digit in pixels, stroke edges included (centred on the icon)
#   stroke  line width in pixels; 1 at 16 px puts every straight line exactly on a pixel row or column
#   outline the contrasting ring around the digit, in pixels

size 16 box 5 7 stroke 1 outline 1
size 20 box 7 10 stroke 2 outline 1
size 24 box 8 12 stroke 2 outline 1
size 32 box 10 16 stroke 3 outline 2
