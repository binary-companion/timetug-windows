# TimeTug for Windows

TimeTug takes over your screen a minute before a meeting starts, so you never hyperfocus through one. This repository is the Windows app: a native Windows 11 application (WinUI 3, .NET 10, MSIX) on the same shared engine as the Mac app, so what and when are identical on both.

Status: under construction (phase 5 of the Windows program). `docs/parity.md` tracks every Mac capability.

- Requires Windows 11 22H2 (build 22621) or later, x64 or ARM64.
- Build and test: see `docs/development.md`.
- Contributing and agent rules: `AGENTS.md`.
