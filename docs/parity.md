# Mac parity ledger

One row per capability of the Mac app (`Apps/macOS/Sources` in `binary-companion/timetug`), every Settings pane and control included. Status is one of:

- **done**: the capability exists on Windows as on the Mac.
- **differs on purpose**: it exists in a Windows shape, or is replaced by the Windows way of doing the same job; Notes say what and why.
- **not applicable**: the Mac capability depends on something Windows does not have (EventKit, Sparkle).
- **later (phase N)**: planned work, owned by that phase of the Windows program: **6** Windows account sign-in (WAM), **7** Windows Widgets, **8** on-device intelligence, **9** Store updates and the cross-distribution notice (Store copy versus website copy). Slice 4 is Store packaging, the groundwork for 9.

This table is the release gate for phase 9: a real release needs every row done, differs on purpose or not applicable, and every "later" row owned by a phase that has shipped (with the reason in Notes). There are no "Soon" placeholders in the app: a capability that is not built is absent, not greyed out.

Slice 3 closed the Settings window: all five Mac panes (General, Appearance, Accounts, Calendars, Tug Rules), About, search and diagnostics are present, and the per-control rows below say which are done, differ on purpose or wait for a later phase.
