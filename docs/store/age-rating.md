# Age rating (IARC questionnaire): draft answers

Partner Center runs the IARC questionnaire when the product is submitted. These are the answers the app supports; the owner enters them and may change any that Partner Center words differently.

| Question | Answer | Why |
| --- | --- | --- |
| Violence, blood, fear, sexual content, nudity, gambling, drugs, alcohol, tobacco, profanity, crude humour | None | A calendar utility. |
| Users can interact or exchange content with other users | No | No accounts of its own, no messaging, nothing is shared between people. |
| Shares the user's location with others | No | |
| Digital purchases or in-app purchases | No | Free, nothing to buy. |
| Unrestricted internet access or links to the web | Links open in the default browser (a meeting's Join link, the website, the privacy page); there is no browser inside the app | The Join button opens a meeting link taken from the person's own calendar event. |
| User-generated content shown to others | No | Calendar content is the person's own and is shown only to them. |
| Collects personal information | The app reads the person's own calendar (titles, times, links, attendees) from the provider they connect and keeps it on their PC; nothing is sent to Binary Companion | See the privacy policy. |
| Expected rating | The lowest, for all ages | |
